# 叮当OKR 角色权限介绍

> 知识库路径：叮当OKR常见问题合集/权限问题

#### **权限简介**

:::
拥有多重身份时，权限会叠加。
:::
- 在空间内等于普通成员；但是有添加、删除、更换企业管理员以获得更多权限的能力
- 拥有企业管理的所有权限；在空间内等于空间主管理员
- 拥有空间内所有的权限
- 拥有被分配的功能权限和管理范围
- 对OKRs、任务、看板设置的可见范围对空间主、子管理员不生效
