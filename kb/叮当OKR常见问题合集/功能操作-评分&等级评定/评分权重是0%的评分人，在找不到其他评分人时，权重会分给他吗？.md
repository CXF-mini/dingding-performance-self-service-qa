# 评分权重是0%的评分人，在找不到其他评分人时，权重会分给他吗？

> 知识库路径：叮当OKR常见问题合集/功能操作-评分&等级评定

不会。**系统默认角色权重是0%，是均分不到权重的**。

如下图：自评权重0%，直属主管权重0%，指定评分人权重100%，如果没有指定评分人，自评人和直属主管权重仍然是0%。
