# Teambition互通互联

> 知识库路径：OKR功能说明

:::
万物皆可OKR之Teambition


开启 Teambition 互联互通后可以实现 OKR 与 Teambition 项目的互相关联，让项目服务于业务目标实现。
:::

### 一、在 Teambition 中启用叮当 OKR 插件

#### **1.1 企业安装应用**

在Teambition的应用商店中，搜索叮当OKR后进行安装使用。

![image.png](assets/f6282cca7e9cdd3d2ebc19cf0a9dbca3.jpg)

![image.png](assets/fad992712c03a7a7119b8d245c2911b1.jpg)

![image.png](assets/348958ea3eeebdffdb3888b8261f2375.jpg)

#### **1.2 项目里启用OKR**

在项目内点击顶部导航的\+号，搜索叮当OKR之后安装到项目。安装之后会显示成已安装。

![image.png](assets/fd89285567ba786901057d850c8a2b7e.jpg)


### **二、OKR 与 Teambition 项目双向关联**

在 OKR 详情中可以点击「选择项目」或粘贴 Teambition 项目链接来进行项目与 OKR 的关联。关联后再 OKR 中可以查看项目的最新进展。点击可以跳转到项目页面。

![OKR／详情／tb.png](assets/b3fe8ec218a28f3f9f1a71b959ad85cf.jpg)

关联过 OKR 的项目，在Teambition项目概览中会展示 OKR 的状态。

![image.png](assets/a63e4a1ddc70b637027fccb02a3d2e2b.jpg)

### **三、用 Teambition 项目进度更新 O、KR**

对于已经关联项目的 OKR，可以在 O、KR 中设置自动更新，以项目的进度来更新 KR 的进度。项目的进度由项目中的任务完成率计算得出。

![image.png](assets/900b1c8e197be45c8340f51082c38422.jpg)

### **四、KR 与 Teambition 任务关联**

3.1 从 KR 关联 Teambition 任务

KR 下支持关联已有的Teambition 任务或者新建 Teambition 任务并关联。已关联的任务会显示在 KR 下方，任务状态与 Teambition 中的任务实时同步，点击可以在 OKR 内打开任务详情页面。

![image.png](assets/eb9fd37f93b1246e441b95123e9f7f85.jpg)

3.2 从 Teambition 的任务关联 KR

在 Teambition 中可以在任务中「关联内容」模块查看已关联的 KR。也可以点击「从资源添加」找到叮当 OKR 进行关联。

![image.png](assets/19ce798784c30e37ef97bf8b058ac3fa.jpg)
