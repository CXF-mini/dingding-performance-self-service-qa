# 获取周期列表

> 知识库路径：叮当OKR开发文档

### 请求地址
```DEFAULT_LANGUAGE
https://oapi.dingteam.com/openapi/okr/main/findAll
```

### 请求方法

POST

### 请求参数

#### Headers

| **参数名称** | **参数值** | **是否必须** | **示例** | **备注** |
|-----------------------------------------------------|--------------------------------------------------|-----------------------------------------------------|-----------------------------------------------|-----------------------------------------------|
| x-dingteam-access-token | 企业凭证token | 是 | | |

### 返回数据

| **名称** | **类型** | **备注** |
|-----------------------------------------------|-----------------------------------------------|-----------------------------------------------|
| code | number | |
| msg | string | |
| data | object\[\] | |
| \- id | string | 周期id |
| \- name | string | 周期名称 |
| \- type | number | 周期类型 1月度 2季度 3半年度 4年度 5自定义 |
| errorData | null | |
| traceId | string | |
