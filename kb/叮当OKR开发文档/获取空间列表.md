# 获取空间列表

> 知识库路径：叮当OKR开发文档

### 请求地址
```DEFAULT_LANGUAGE
https://oapi.dingteam.com/openapi/okr/space/list
```

### 请求方法

POST

| **参数名称** | **参数值** | **是否必须** | **示例** | **备注** |

| x-dingteam-access-token | 企业凭证token | 是 | | |
