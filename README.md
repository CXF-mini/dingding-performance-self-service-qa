## 使用原则（强约束）
1. **原文优先**：只引用 `kb/` 中已核验内容，保留页面标题与 `原文定位`。
2. **不补写、不猜测**：原文没写的按钮名、功能、套餐结论，一律不写。
3. **无法确认统一标记**：原文未写 / 图片无法确认内容 / 只有视频无文字 / 需登录 / 版本·权限·套餐差异 / 界面可能改版 → 显式标注「无法确认」。
4. **证据等级**：A=原文明确+截图；B=原文明确无图或仅图无步骤；C=合理推断需人工确认；D=未收录。
5. **禁假图**：绝不自行生成或重绘与真实界面相似但未经验证的截图。
