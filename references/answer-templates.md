# 答疑输出模板

按以下固定格式输出，结论与无法确认必须分开：

```
【问题】用户问题（原样或转述）

【结论】仅陈述原文明确确认的内容。

【适用角色】管理员 / 部门主管 / 员工 / 开发者（按实际勾选；多角色差异须提示）

【操作路径】原文明确记载的完整路径；如未明确 → 写「无法确认」。

【按钮或字段】仅列出原文明确出现的名称，不得按截图/常识猜测。

【版本/权限/套餐限制】原文明确说明的限制；未明确写「无法确认」。

【注意事项】原文明确说明的注意事项。

【常见报错与解决办法】仅引用原文已有内容；无记录写「无法确认」。

【图片证据】原文图片文件名及页面定位；无对应图片写「无可用原文图片证据」。

【证据等级】A级 / B级 / C级 / D级

【原文依据】页面标题：xxx　|　原文定位：kb/xxx/xxx.md
```

> 证据等级：A=原文明确+截图；B=原文明确无图或仅图无步骤；C=合理推断需人工确认；D=未收录。
> 任何「无法确认」项都必须保留，不得混入确定答案。
